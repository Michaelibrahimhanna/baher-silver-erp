## Database Migration Overview

Sprint 01 creates five database models in `apps/api-backend/prisma/schema.prisma` for manufacturing and production management: `WorkCenter`, `ManufacturingOrder`, `MaterialReservation`, `WorkCenterQueueJob`, and `ManufacturingOperationLog`.

---

## Database Models Defined

### 1. `WorkCenter`

```prisma
model WorkCenter {
  id             String   @id @default(uuid())
  code           String   @unique // e.g. 'WC-CASTING', 'WC-POLISHING', 'WC-SETTING', 'WC-RHODIUM', 'WC-QC'
  nameAr         String
  nameEn         String
  capacityHourly Float    @default(10.0)
  hourlyCostRate Float    @default(0.0)
  isActive       Boolean  @default(true)
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
}
```

---

### 2. `ManufacturingOrder`

```prisma
model ManufacturingOrder {
  id                           String    @id @default(uuid())
  moCode                       String    @unique // Generated by NumberingEngine e.g. "MO-2026-000101"
  productModelId               String
  variantId                    String?
  plannedQuantity              Int       @default(1)
  completedQuantity            Int       @default(0)
  scrappedQuantity             Int       @default(0)
  targetSilverPurity           String    @default("925")
  estimatedSilverWeightGrams   Float     @default(0.0)
  actualSilverWeightGrams      Float     @default(0.0)
  silverLossWeightGrams        Float     @default(0.0)
  status                       String    @default("PLANNED") // PLANNED | CONFIRMED | IN_PROGRESS | QUALITY_CHECK | COMPLETED | CLOSED | CANCELLED
  priority                     String    @default("MEDIUM")  // LOW | MEDIUM | HIGH | URGENT
  startDate                    DateTime?
  completionDate               DateTime?
  targetDate                   DateTime?
  supervisorId                 String?
  supervisorName               String?   @default("مشرف الإنتاج")
  notes                        String?
  createdAt                    DateTime  @default(now())
  updatedAt                    DateTime  @updatedAt

  @@index([moCode])
  @@index([status])
  @@index([productModelId])
}
```

### 3. `MaterialReservation`

```prisma
model MaterialReservation {
  id               String   @id @default(uuid())
  moId             String
  lineType         String   // SILVER_BULLION | STONE | RAW_MATERIAL | CHEMICAL | COMPONENT
  itemId           String?
  itemCode         String
  itemName         String
  requiredQuantity Float
  reservedQuantity Float    @default(0.0)
  consumedQuantity Float    @default(0.0)
  unitOfMeasure    String   @default("g")
  status           String   @default("RESERVED") // RESERVED | CONSUMED | RELEASED
  createdAt        DateTime @default(now())

  @@index([moId])
  @@index([lineType])
}
```

### 4. `WorkCenterQueueJob`

```prisma
model WorkCenterQueueJob {
  id               String    @id @default(uuid())
  workCenterId     String
  moId             String
  sequenceNo       Int       @default(10) // 10, 20, 30, 40...
  operationStage   String    // CASTING, FILING_POLISHING, STONE_SETTING, RHODIUM_PLATING, QC
  status           String    @default("QUEUED") // QUEUED | IN_OPERATION | COMPLETED | SKIPPED
  estimatedMinutes Int       @default(0)
  actualMinutes    Int       @default(0)
  operatorId       String?
  operatorName     String?
  startedAt        DateTime?
  completedAt      DateTime?
  createdAt        DateTime  @default(now())

  @@index([workCenterId])
  @@index([moId])
  @@index([status])
}
```

---

### 5. `ManufacturingOperationLog`

```prisma
model ManufacturingOperationLog {
  id               String   @id @default(uuid())
  moId             String
  workCenterId     String?
  sequenceNo       Int      @default(10)
  stage            String   // WAX | CASTING | POLISHING | SETTING | RHODIUM | QC
  quantityPassed   Int      @default(0)
  quantityScrapped Int      @default(0)
  scrapReason      String?  // POROSITY | CASTING_DEFECT | OVER_POLISHING | STONE_BREAKAGE | DIMENSIONAL_MISMATCH | OTHER
  scrapWeightGrams Float    @default(0.0)
  estimatedMinutes Int      @default(0)
  actualMinutes    Int      @default(0)
  operatorId       String?
  operatorName     String?  @default("النظام")
  notes            String?
  timestamp        DateTime @default(now())

  @@index([moId])
  @@index([workCenterId])
  @@index([timestamp])
}
```

## Migration Steps Executed

1. Updated `apps/api-backend/prisma/schema.prisma`.
2. Executed `npx prisma db push` to synchronize SQLite `dev.db`.
3. Executed `npx prisma generate` to re-generate TypeScript `@prisma/client` types.
